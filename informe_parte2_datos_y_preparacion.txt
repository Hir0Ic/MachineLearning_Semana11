--------------------------------------------------------------------------------
- Fuente original: Wine Dataset - UCI Machine Learning Repository (Aeberhard & Forina, 1992).

3.3.3 Análisis de heterogeneidad de escalas de medición
--------------------------------------------------------------------------------
Las magnitudes de las variables químicas presentan diferencias de hasta cuatro órdenes de magnitud:
- 'proline' oscila entre 278.0 y 1680.0 mg/L (media = 746.89, rango = 1402.0).
- 'magnesium' oscila entre 70.0 y 162.0 mg/L (media = 99.74, rango = 92.0).
- 'nonflavanoid_phenols' oscila entre 0.13 y 0.66 g/L (media = 0.36, rango = 0.53).

Impacto técnico: Si las variables se introducen sin transformar, los algoritmos basados en distancias
euclídeas (K-Means, DBSCAN y PCA) se verán sesgados y dominados casi al 100% por 'proline' y 'magnesium',
dejando sin peso analítico a los flavonoides y polifenoles. Esto exige una estandarización obligatoria.

3.4.1 Aislamiento de la matriz X y principio del aprendizaje no supervisado
--------------------------------------------------------------------------------
Para garantizar un proceso de agrupamiento genuino y no supervisado, la columna externa 'target'
fue excluida por completo. La matriz resultante X comprende 178 filas y 13 columnas cuantitativas.


3.4.2 Formulación matemática y comparación teórica de decisiones
--------------------------------------------------------------------------------
Se compararon dos estrategias metodológicas de preparación de características:

* Decisión A: StandardScaler (Z-Score)
  Fórmula matemática: z = (x - mu) / sigma
  Centra en media = 0 y escala a desviación estándar = 1.
  Idoneidad: Es la formulación óptima para K-Means y PCA, ya que ambos algoritmos asumen esfericidad
  e igualdad de varianzas en las dimensiones del espacio euclídeo.

* Decisión B: RobustScaler (Centrado en Mediana y rango intercuartílico)
  Fórmula matemática: z = (x - Mediana) / IQR, donde IQR = Q3 - Q1
  Centra en mediana = 0 y escala en unidades IQR = 1.
  Idoneidad: Reduce la influencia de outliers, pero produce varianzas heterogéneas entre variables,
  lo que debilita el cálculo de autovalores en PCA.

3.4.4 Justificación técnica de la elección de la matriz X final
--------------------------------------------------------------------------------
Se adoptó definitivamente la Decisión A (StandardScaler) para conformar la matriz X final de (178, 13).
Motivos:
1. Permite que K-Means optimice centroides sin sesgo hacia ninguna dimensión.
2. Garantiza que PCA calcule componentes principales basados en covarianza normalizada pura.
3. La tasa de outliers encontrada en el EDA (< 2.5%) no causa distorsión crítica sobre la media muestral.

3.5.2 Script reproducible en Python (Para anexo de código del informe)
--------------------------------------------------------------------------------
```python
import numpy as np
import pandas as pd
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler

# 1. Fijar semilla aleatoria para reproducibilidad
RANDOM_STATE = 42
np.random.seed(RANDOM_STATE)

# 2. Carga del conjunto de datos original
wine = load_wine(as_frame=True)
df = wine.frame

# 3. Aislamiento de la matriz de características X (sin etiqueta externa)
features = [col for col in df.columns if col != "target"]
X_raw = df[features].copy()

# 4. Ajuste y transformación mediante StandardScaler
scaler = StandardScaler(with_mean=True, with_std=True)
X_scaled = pd.DataFrame(scaler.fit_transform(X_raw), columns=features)

# Verificación de integridad de la matriz X preprocesada
print(f"Dimensiones de X preprocesada: {X_scaled.shape}")
print(f"Media global promedio: {X_scaled.mean().mean():.4f}")
print(f"Varianza global promedio: {X_scaled.var().mean():.4f}")
```
